title: "1. Kitendakazi Ndani ya Kingine"
task: "Badilisha `salamu('Dunia')` kuwa jina lako mwenyewe na uone kitakachotokea."
initialCode: |
  fanya salamu = unda(jina) {
      andika("Habari,", jina)
  }

  fanya anza = unda() {
      salamu("Dunia")
      andika("Programu imekamilika.")
  }

  anza()
solution: |
  fanya salamu = unda(jina) {
      andika("Habari,", jina)
  }

  fanya anza = unda() {
      salamu("Amani")
      andika("Programu imekamilika.")
  }

  anza()
---
Katika Nuru, kitendakazi (function) ni kama mfanyakazi. Unaweza kumwambia mfanyakazi mmoja amuite mfanyakazi mwingine ili amsaidie.

Hapa tuna kitendakazi `anza` ambacho kinamuita `salamu` kumsaidia kutoa ujumbe. Hii inatusaidia kuweka msimbo wetu ukiwa safi na nadhifu.
