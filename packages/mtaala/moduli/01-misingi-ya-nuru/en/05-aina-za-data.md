The computer works with different types of data. These are the ones you will use most:

- **Namba**: whole number, like `25` or `-3`
- **Desimali**: number with a decimal point, like `2.5` or `0.75`
- **Neno**: text inside quotes, like `"Arusha"`
- **Boolean**: a yes or no answer, like `kweli` or `sikweli`

To find out the type of something, use `aina()`:

```nuru
andika(aina(25))       // NAMBA
andika(aina("Arusha")) // NENO
```

### Arithmetic

- `+` add: `7 + 3` is `10`
- `-` subtract: `7 - 3` is `4`
- `*` multiply: `7 * 3` is `21`
- `/` divide: `7 / 2` is `3.5`
- `%` remainder: `7 % 3` is `1`

```nuru
fanya wanafunzi = 45
fanya makundi = 5
andika(+++wanafunzi / makundi+++) // each group has 9 students
```
