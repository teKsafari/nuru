---
title: "Petal Flower"
task: "The function `petali()` already draws one petal. Call it `8` times inside a loop, turning right `45` degrees after each petal, to get a whole flower."
---
Great artists build big pictures out of small pieces. So can you!

A function can hold a whole drawing. Once you have `petali()`, you can draw a petal with a single line, anywhere you like.

```nuru
tumia kobe

fanya mraba = unda(upande) {
    kwa i ktk mfululizo(4) {
        kobe.mbele(upande)
        kobe.kulia(90)
    }
}

// 12 squares, each one turned a little
kwa i ktk mfululizo(12) {
    +++mraba(100)+++
    kobe.kulia(30)
}
```

This is the secret of decorative patterns: draw one shape, turn a little, repeat. For a flower with 8 petals, each turn is `360 / 8 = 45`.
