Wasanii wakubwa wanajenga picha kubwa kwa vipande vidogo. Wewe pia unaweza!

Kitendakazi kinaweza kubeba mchoro mzima. Ukishakuwa na `petali()`, unaweza kuchora petali kwa mstari mmoja tu, popote unapotaka.

```nuru
tumia kobe

fanya mraba = unda(upande) {
    kwa i ktk mfululizo(4) {
        kobe.mbele(upande)
        kobe.kulia(90)
    }
}

// Miraba 12, kila mmoja umegeuzwa kidogo
kwa i ktk mfululizo(12) {
    +++mraba(100)+++
    kobe.kulia(30)
}
```

Hii ndiyo siri ya michoro ya mapambo: chora umbo moja, geuka kidogo, rudia. Kwa ua lenye petali 8, kila geuko ni `360 / 8 = 45`.
